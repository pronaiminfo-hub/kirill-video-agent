Политика конфиденциальности Kirill Video Agent

Обновлено 27 сентября 2026 года

Кто пользуется программой

Kirill Video Agent - личная программа владельца YouTube-канала. Она работает на его компьютере. Других пользователей у программы нет.

Какие данные получает программа

С разрешения владельца, через YouTube API Services, программа получает данные только его собственного канала: сведения о канале и роликах, аналитику канала, субтитры и комментарии к его роликам. Загружает и изменяет ролики программа только по прямой команде владельца. Удалять ролики программа не умеет.

Где хранятся данные

Данные и ключ доступа хранятся только на компьютере владельца. Программа не отправляет их на свои серверы, потому что своих серверов у неё нет. Данные не продаются, не передаются рекламным сетям и не используются для рекламы.

Для анализа своего канала владелец пользуется ИИ-ассистентом Claude компании Anthropic. Данные канала передаются ассистенту только во время работы, по запросу владельца.

Использование данных, полученных через API Google, соответствует правилам Google API Services User Data Policy, включая требования Limited Use.

Сервисы YouTube и Google

Программа использует YouTube API Services. Пользуясь программой, владелец соглашается с Условиями использования YouTube. Как Google обращается с данными, описано в Политике конфиденциальности Google.

Как отозвать доступ и удалить данные

Отозвать доступ программы к аккаунту можно в любой момент на странице настроек безопасности Google. После этого программа перестаёт получать данные. Сохранённые данные владелец удаляет со своего компьютера сам.

English: Privacy Policy

Last updated September 27, 2026

Who uses the app. Kirill Video Agent is a personal tool of a YouTube channel owner. It runs on the owner's own computer and has no other users.

What data it accesses. With the owner's authorization, through YouTube API Services, the app accesses data of the owner's own channel only: channel and video information, channel analytics, captions and comments on the owner's videos. It uploads and edits videos only on the owner's explicit command. It cannot delete videos.

Storage and sharing. Data and access tokens are stored only on the owner's computer. The app has no servers of its own. Data is not sold, not shared with advertising networks and not used for advertising. The owner uses the AI assistant Claude by Anthropic to analyze the channel; channel data is passed to it only during a working session, at the owner's request. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google. The app uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service. See the Google Privacy Policy.

Revoking access and deleting data. Access can be revoked at any time via the Google security settings page. Stored data is deleted by the owner from their own computer.
