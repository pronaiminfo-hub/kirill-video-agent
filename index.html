Kirill Video Agent

Личная программа владельца YouTube-канала. Она работает на его компьютере и помогает вести канал: показывает аналитику роликов, загружает новые ролики и меняет их названия и описания. Пользуется программой только владелец канала.

Программа работает через YouTube API Services, официальный интерфейс YouTube для программ.

Политика конфиденциальности · Условия использования

English

Kirill Video Agent is a personal tool of a YouTube channel owner. It runs on the owner's own computer and helps manage the channel: it reads channel analytics, uploads new videos and edits their titles and descriptions. Only the channel owner uses it.

The app uses YouTube API Services.
